# Coin Flipper

Six coins on the screen. A tap flips a coin.

## What it does

A three-column grid shows a dollar, a euro, a yen, a pound, a ruble, and a bitcoin. A tap rotates that coin by 180 degrees.

## Stack

SwiftUI.

## Run

```bash
git clone https://github.com/dpogonia/CoinFlipper-HUDSON.git
cd CoinFlipper-HUDSON
open CoinFlipper.xcodeproj
```

Run the **CoinFlipper** scheme on an iPhone simulator.
