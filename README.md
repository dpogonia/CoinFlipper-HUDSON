# Coin Flipper

Шесть монет на экране. Касание переворачивает монету.

## Что умеет приложение

Сетка из трёх колонок: доллар, евро, иена, фунт, рубль и биткоин. По нажатию монета поворачивается на 180 градусов.

## Стек

SwiftUI.

## Запуск

```bash
git clone https://github.com/dpogonia/CoinFlipper-HUDSON.git
cd CoinFlipper-HUDSON
open CoinFlipper.xcodeproj
```

Запустите схему **CoinFlipper** на симуляторе iPhone.
